# Changelog

## v1.0.2

- Fixed: watching a channel always showed Twitch's "content is unavailable / Browse channels" page. Twitch retired the old pop-out player address, so PhosphorWatch now uses player.twitch.tv.

## v0.1.0

First release.

- Always-on-top, resizable window that plays one Twitch stream with Twitch's own pop-out player (Edge WebView2).
- Sign in to Twitch once inside the app; subscriber / Turbo ad-free viewing applies like in a browser.
- Channel box (name or twitch.tv link) and a favorites list you can reorder.
- Hover bar over the stream: move, channels, menu, always on top, minimize, close. Drag the edges to resize.
- The same 18 CRT palettes as Phosphor XP and Phosphor Count, plus an opacity setting.
- Checks GitHub for new releases and installs them with one click.
